Increment elevation

 

 

Toolbar:  

 

Menu: CAD-Earth > Mesh > Mesh Explorer.

Mesh Explorer node:

 

Context Menu: Vertices > Increment elevation

 

Command line: CE_MESHEXPLORER

 

CAD-Earth version: Premium.

 

Command description:

 

 

Using this command, you can increment a selected vertex's elevation or increment the elevation of vertices inside a closed polygon defined by picking points over the mesh.

Every time you select the 'Continue' option, the increment value specified will be added to the last calculated elevation.

 

 

Command line prompts:

 

Increment<0.10>:

Select: [Point/Area/Exit]<P>:

 

If the point option is selected:

 

Select point or [Exit]:

[Continue/Increment/Exit]<C>:

 

If the area option is selected:

 

Select: [Point/Area/Exit]<P>: A

Select first point [or ENTER to exit]:

Select next point or [Undo]:

Select next point or [Undo]:

Select next point or [Undo]:

...

[Continue/Increment/Exit]<C>:

 

If the increment option is selected:

 

Increment<0.10>:

 

Tips:

 

•Select an isometric view before using this command to see more clearly the effect of each elevation increment applied.
