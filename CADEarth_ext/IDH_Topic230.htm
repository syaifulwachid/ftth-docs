Error and alert messages.

 

 

Some common error and alert messages are shown when using some CAD-Earth commands. Below is a table listing these messages and their recommended solutions.

If you encounter an error or alert message not listed here, please send us a description and if possible a screen capture of the message to support@cad-earth.com or submit a support ticket.

 

 

Problem or Error/alert messages

Description/recommended solution

Fatal error: <Error description>. AutoCAD can't continue.

AutoCAD freezes or commands too slow to execute.

The CAD-Earth main DLL file is not in sync with the Google Earth installed version. Double click the file GEINTEROP.EXE located in the CAD-Earth installation directory (usually in C:\Program Files\CAD-Earth (CAD version)' and try again. If this doesn't solve the problem please contact support@cad-earth.com or submit a support ticket for a solution to this problem.

Internet connection not found.

Check and solve access problems to your Internet connection.

The UTM zone selected (UTM zone value) does not correspond with the UTM zone of the place (UTM zone value).This may cause incorrect coordinate conversions. Continue?

Select the correct UTM zone from the list in the 'Datum Settings' tab of the corresponding CAD-Earth command dialog box. If the site is between two UTM zones you can disregard this alert message and check results.

The hemisphere selected (South) does not correspond with the hemisphere of the place (North). This may cause incorrect coordinate conversions. Continue?

Select the correct hemisphere in the 'Datum Settings' tab of the corresponding CAD-Earth command dialog box. If the equatorial line crosses the site you can try both the North and South hemisphere to see which one produces the most accurate results.

Google Earth default KML file not found.

Check if Google Earth is properly installed. Re-install Google Earth. If error continues contact technical support.

CAD-Earth module is not authorized. Function not available.

You selected a CAD-Earth command from a module that is not authorized. An upgrade license must be bought to obtain the authorization key.

CAD-Earth license has been deactivated. Function not available.

Re-apply the authorization key in the CAD-Earth applying the license again. Contact technical support.

Error reading KML file:<Error description>

An error occurred reading data from a Google Earth KML file. Send the error description and KML file to support@cad-earth.com or submit a support ticket for a solution to this problem.

There are not any valid nodes selected.

Please check at least one valid node.

This alert message appears when importing objects from Google Earth and no selection was made. Select at least one item in the explorer.

Server connection unavailable.

Check and solve access problems to your Internet connection.

Error initializing Google Earth interface.

Double click the file GEINTEROP.EXE located in the CAD-Earth installation directory (usually in C:\Program Files \CAD-Earth (CAD version)' and try again. If this doesn't solve the problem please contact support@cad-earth.com or submit a support ticket for a solution to this problem.

No valid objects found in KML file. Please open Google Earth and add valid polygons, routes and/or placemarks.

While trying to import objects from a Google Earth KML file no valid objects were found. Open Google Earth to see if valid objects are found in the 'My Places' folder and add them if necessary.

The KML file size about to be processed is more than <size>MB. It may take several minutes to read this information. Do you wish to continue?

The KML file has a lot of information. Generally files up to 50MB can be processed in less than a minute. If it takes too long to load the file divide it in several KML files. (See how to save information to a KML file video).

Selected color is already assigned to another range. Please select another color.

Select a color for the slope zone analysis range that is not already used.

Ending range value must be greater than the range start value.

Set an ending percentage value for the current range greater than the range start percentage value. Example: If the starting range percentage value es 20% the ending percentage value must be greater than 20%.

Select at least one type of annotation.

Select the annotate elevation and/or station option for profile annotation.

Distance between station annotations must be a multiple of vertical grid lines spacing

Set the profile/cross section vertical grid separation as a  multiple of the distance between station annotations. For example, if the distance between station annotations at the bottom of the profile/cross section grid is set to 10 feet, vertical grid lines separation may be set to any value multiple of 10 (10, 20, 30, etc.).

Distance between elevation annotations must be a multiple of horizontal grid lines spacing

Set the profile/cross section horizontal grid separation as a multiple of the distance between elevation annotations. For example, if the distance between elevation annotations at the left of the profile/cross section grid is set to 10 feet, horizontal grid lines separation may be set to any value multiple of 10 (10, 20, 30, etc.).

Left/right padding distance must be a multiple of vertical grid lines spacing.

Set the margin distance at the left and right of the profile as a multiple of the distance between vertical grid lines. For example, if you set the vertical lines distance at every 5 feet, the left/right margin can be set to any value multiple of 5 (5, 10, 15, etc). You can also set the left/right padding value equal to zero.

Top/Bottom padding distance must be a multiple of horizontal grid lines spacing

Set the margin distance at the top and bottom of the profile as a multiple of the distance between horizontal grid lines. For example, if you set the horizontal lines distance at every 5 feet, the top/bottom margin can be set to any value multiple of 5 (5, 10, 15, etc). You can also set the top/bottom padding value equal to zero.

Placemark icon <icon name> is already added.

Select a custom icon name not already included in the Custom Placemark Icon Library.

Relative path cannot be assigned.

Select a folder that can be relative to the current drawing path (in the same drive).

Drawing must be saved before inserting an image with no path.

Save the current drawing and try again. If you specify to insert a georeferenced image with no path, it must be located in the same directory as the drawing.

Offset distance left or right must be non zero.

Horizontal distance (offset) from the center of the cross section to the right and left end can't be both zero. Set an offset value different than zero for one or both ends.

Index contour interval must be a multiple of contour lines interval

Set index contour separation as a multiple of the contour lines interval value. For example, if you have specified to draw contour lines at every 5 feet, the index contour interval must be a multiple of 5 feet (10, 15, 20, etc).

CAD-Earth ARX file couldn't be loaded

Wrong or damaged CAD-Earth main ARX file. Re-install CAD-Earth. If problem persists contact technical support or submit a support ticket.

This command doesn't work in 3D or isometric views. Please reset the view perpendicular to the XY plane

Some CAD-Earth commands don't work in isometric or perspective view. Use the PLAN AutoCAD command to set view perpendicular to the XY plane.

Terrain mesh couldn´t be created.

Error: Unhandled exception <value>

Problem triangulating mesh points. Try  the command again with different parameters (grid rotation, distance between rows and columns and point of origin). If error persists contact technical support or submit a support ticket.

Contour lines couldn´t be created.

Reduce the contour and index lines interval. This problem often occurs when the terrain mesh is almost an horizontal plane.

Mesh group not found.

Mesh can´t be made invisible.

Contour lines must be generated before toggling mesh visibility.

Dialog box couldn't be initialized.

Dialog box of the selected CAD-Earth command couldn't be shown. Contact technical support or submit a support ticket.

World file missing

Copy the world file to the same folder as the georeferenced image file.

Error reading world text file (file path).

Wrong world file format. Open the file with a text editor to see its contents to make sure it's not damaged or altered.

If problem persists contact technical support or submit a support ticket.

"Google Earth application not found" or "Problem connecting with Google Earth."

 

•Right click on the file GEINTEROP.EXE and select 'Run as Administrator' from the context menu. This file is located in the folder where CAD-Earth is installed (usually C:\Program Files\CAD-Earth).

•Close Google Earth and try the CAD-Earth command again.

•Restart AutoCAD.

If problem persists contact technical support or submit a support ticket.

Imported image appears blank

From the Google Earth menu select Tools > Options > 3D View > Graphics Mode > DirectX and restart Google Earth.

If you have several monitors connected to your computer deactivate them and leave only one monitor active.

Image appears with gaps between image tiles.

•Right-click on your Windows Desktop screen

•Select 'Display settings' from the context menu.

•Set the screen scale factor to 100%

Check that the screen scale factor shown in the dialog box when importing or inserting an image is the same as the screen scale factor set in your computer.

Percentage progress bar is shown in the final image.

Uncheck the option 'Display percentage bar' when importing or inserting an image.
