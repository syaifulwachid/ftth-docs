Installation

 

Installation requirements

 

Currently, CAD-Earth works in the following CAD/Windows/Google Earth versions:

 

•AutoCAD Full and AutoCAD based product versions 2018 through 2024, 64 bits.

•BricsCAD Pro/Platinum V19-20 64 bits

•Windows 8/10 64 bits.

•Google Earth Free/Pro 64 bits

 

Computer requirements 

 

CAD-Earth doesn't need any additional computer requirements beyond what's needed to run your CAD program optimally.

You must have an Internet connection if you are going to import images or terrain meshes from Google Earth.

 

 

Installation troubleshooting

 

When you run the CAD-Earth setup program the following tasks are done automatically:

 

•The CAD-Earth main installation folder and subfolders are created, and the corresponding files are copied.

•Shortcuts are created and installed in the computer Desktop, the Start Menu and/or in the Quick Launch Windows toolbar.

•CAD-Earth DLL and EXE files are executed or registered in the Windows Registry.

•The CAD-Earth installation and bitmap folders are added to the AutoCAD Support File Search Path. This folders are also added to the Trusted Application Paths (AutoCAD users)

•If you have multiple AutoCAD based products installed in your computer, a dialog box may be shown to select the AutoCAD product you wish to launch with CAD-Earth.

•The CAD-Earth menu and toolbar is loaded at AutoCAD startup.

 

 

If any of this tasks are not completed successfully, some error and alert messages may appear or problems may occur.

The recommended course of action to correct installation problems is to reinstall CAD-Earth making sure you have administrator rights and restart your computer.

If after reinstalling CAD-Earth the problems are not corrected, please consult the following Installation Problems Table and follow the recommended solution.

If you still can not solve the problem, please contact us at support@cad-earth.com or submit a support ticket.

 

 

CAD-Earth Installation Problems

Problem Description

Recommended Solution

CAD-Earth icon shortcuts are not added to the Windows Desktop, Start Menu or Quick Launch bar

Reinstall CAD-Earth with using a Windows User account with administration rights.

When selecting a CAD-Earth shortcut icon an alert message is shown informing that a valid AutoCAD version can't be found.

Make sure you have a valid AutoCAD product installed in your computer and that you have installed the correct CAD-Earth version for your AutoCAD product. (CAD-Earth doesn't work with AutoCAD LT versions.)

The CAD-Earth menu and toolbar are not visible in the AutoCAD screen.

Load the CAD-Earth menu using the MENULOAD AutoCAD command. Select the 'Browse' button and then select the file cadearth.mnu and the select the 'Load' button. (You may have to change the Files of Type selection to *.mnu in the Select Customization File dialog box before selecting the menu file).

When selecting a command from the CAD-Earth menu or toolbar and 'Unknow command' message is shown and nothing happens.

 

Question mark icons are shown in the toolbar buttons instead of the CAD-Earth command icons.

•Select 'Tools' from the AutoCAD menu

•Select 'Options' at the bottom of this menu

•Select the 'Files' tab

•Expand the 'Support File Search Path' tree node.

•Click the 'Add' button.

•Click the 'Browse..' button.

•Select the CAD-Earth folder (usually C:\Program Files\CAD-Earth)

•Select the CAD-Earth bitmap folder (usually C:\Program Files \CAD-Earth\BMP)

•Click the 'OK' button.

•Restart AutoCAD

 

When AutoCAD is starting, and 'File Loading - Security Concern' message is displayed stating that 'An executable file was found outside the specified trusted locations' and asks what to do with the CAD-Earth exe file.

•Select 'Tools' from the AutoCAD menu

•Select 'Options' at the bottom of this menu

•Select the 'Files' tab

•Expand the 'Trusted Locations'.

•Click the 'Add' button.

•Click the 'Browse..' button.

•Select the CAD-Earth folder (usually C:\Program Files\CAD-Earth)

•Select the CAD-Earth bitmap folder (usually C:\Program Files \CAD-Earth\BMP)

•Click the 'OK' button.

•Restart AutoCAD

When selecting a CAD-Earth shortcut icon nothing happens.

•Reinstall CAD-Earth with using a Windows User account with administration rights.

 

If this doesn't correct the problem, please do the following:

•Right click on the CAD-Earth shortcut icon.

•Select 'Properties'

•Select the 'Shortcut tab'

•Click the 'Select file location' button.

•Select the file CADEARTH.EXE located in the CAD-Earth installation folder (usually C:\Program Files\CAD-Earth)

•Manually type the version number after the target path:

 

 

For AutoCAD 2018, add a blank space and the number 22 at the target path end:

 

"C:\Program Files\CAD-Earth (AutoCAD 2018)\cadearth.exe" 22

 

For AutoCAD 2019-2020, add a blank space and the number 23 at the target path end:

 

"C:\Program Files\CAD-Earth (AutoCAD 2019-2020)\cadearth.exe" 23

 

For AutoCAD 2021-2024, add a blank space and the number 24 at the target path end:

 

"C:\Program Files\CAD-Earth (AutoCAD 2021)\cadearth.exe" 24
