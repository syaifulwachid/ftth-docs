Export terrain mesh to LandXML

 

Toolbar:  

 

Menu: CAD-Earth > Mesh commands > Export mesh to LandXML

 

Command line: CE_MESHTOLANDXML

Prompts:

 

Select triangulation mesh:

Filename:

CAD-Earth version: Plus, Premium.

 

Command description:

 

Using this command the point and triangle data from a selected terrain mesh can be exported to a file according to the LandXML format specification. This file can then be read by other software applications such as Civil3D© to create surfaces from a LandXML file.

 

Tips:

 

•To create a surface from a LandXML file in Civil3D© select File > Import >  Import LandXML from the screen menu and select the file created by this command.

•The Civil3D© surface imported from a LandXML file will be created in the same position as the exported terrain mesh, so you might have to move one of them to avoid having two superimposed objects.
