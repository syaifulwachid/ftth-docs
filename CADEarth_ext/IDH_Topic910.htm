Refine triangulation border

 

Toolbar:  

 

Menu: CAD-Earth > Mesh > Mesh Explorer.

Mesh Explorer node:

 

Context Menu: Triangulation > Refine triangulation border

 

Command line: CE_MESHEXPLORER

 

Command line prompt:

 

Select: [Area/Polyline]<A>

CAD-Earth version: Premium.

 

Command description:

 

Triangles on the mesh boundary will be removed according to the parameters specified.

 

 

 

ØMinimum triangle internal angle. (Decimal degrees) Triangles that have a vertex with an internal angle less or equal to the value specified, will be removed.

ØMaximum triangle side length. (Drawing units) Triangles that have a side equal or greater than the value specified, will be removed.

 

Tips:

 

•Use this command to automatically remove elongated triangles on the terrain mesh boundary causing wrong terrain configurations.

•You can also manually delete triangles at the mesh boundary by defining an area.
