Set sun position

 

 

 

Toolbar:   

 

Menu: CAD-Earth > Mesh commands > Mesh Viewer

 

Command line: CE_MESHVIEWER

Mesh Viewer toolbar:

CAD-Earth version: Premium.

 

Command description:

 

Update the sun position specifying azimuth and elevation angles or selecting a point inside a circular graph. The current image displayed in the Mesh Viewer will be updated when you change the sun position.

 

 

 

 

Tips:

 

•You can enter the angle in decimal degrees in any numeric box and when you press ENTER or exit the box, the remaining degree, minute and seconds values will be calculated automatically.

•The azimuth angle is measured from the north axis in a clockwise direction from 0 to less than 360. The elevation angle is measured from the XZ plane from 0 to 90. All angles are decimal degrees.

•To see the lighting effect more clearly, you can unlink the image from the mesh to display it in a single color and adjust the color contrast and intensity.
