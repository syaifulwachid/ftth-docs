Make animated video

 

 

Toolbar:   

 

Menu: CAD-Earth > Mesh commands > Mesh Viewer

 

Command line: CE_MESHVIEWER

Mesh Viewer toolbar:

CAD-Earth version: Premium.

 

Command description:

 

Use this command to create mp4 animated video files by defining keyframes containing camera position and view direction, speed and pause time. You can preview the animation inside the Mesh Viewer before creating the final video animation file.

 

 

Tool window to create an animated video file

 

 

Button

Description

Go to first keyframe.

Go to previous keyframe.

Go to next keyframe.

Go to last keyframe.

Play animation from the beginning. The animation will play in the Mesh Viewer from the first keyframe.

Play animation. The animation will play in the Mesh Viewer from the current keyframe.

Pause animation. Current animation in Mesh Viewer will stop.

Create video animation file. An mp4 video file will be created interpolating speed and camera position and view direction defined in each keyframe.

Load animation sequence. Load keyframe data from a previously saved animation sequence.

Start new animation sequence. All keyframes will be deleted to add new keyframes.

Save animation sequence. A dialog box will be displayed to enter the animation sequence name and description.

Video animation settings. You can select the video information that will be displayed, the video file format and if the video file will be played in the Windows Media Player when finished.

Add keyframe. The specified speed, pause time and current camera position and view direction will be saved in a new keyframe and added to the animation sequence.

Delete current keyframe. 

 

Tips:

 

•          Move the camera to the desired view and press the add keyframe button to save the current camera position, view direction, speed and pause time specified.

•          At least two keyframes must be defined to interpolate camera position and view direction at intermediate frames according to the speed and pause time specified for each keyframe.

•You only need to define keyframes at the start and end of a linear path, or when a camera view direction changes along the path. The intermediate frame data will be automatically calculated interpolating the camera position and view direction between the start and end keyframe.

•Specifying different speed values between keyframes will produce an acceleration or deceleration effect.

•If you save an animation sequence, you must select to save changes when you close the Mesh Viewer and save the drawing to permanently store the information.

•You can preview the animation in the Mesh Viewer before creating the video file. You can start the animation from the current keyframe or from the first keyframe and stop the animation when necessary.
