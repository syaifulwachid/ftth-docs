Checkout license

 

Toolbar:   

 

Menu: CAD-Earth > License Management > Checkout license

 

Command line: CE_LICENSECHKOUT

 

CAD-Earth version:  Basic, Plus, Premium.

 

Command description:

 

This command is used to free and return a license to the pool of available licenses. Once a license is freed, it can be used by another computer.

If you close AutoCAD, the license will be freed automatically, and there's no need to use this command. As soon as a CAD-Earth command is used in any computer that has been previously authorized applying a license, an available license will be taken from the pool.

 

 

Tips:

 

•There's no CAD-Earth license check-in command, the license will be taken automatically from the pool of available licenses as soon as you start using a CAD-Earth command.

•You must have an Internet connection to do a license checkout.

•You can use the command to get licenses information to see which licenses are being used and which ones are available.

•CAD-Earth demo licenses can't be freed.
