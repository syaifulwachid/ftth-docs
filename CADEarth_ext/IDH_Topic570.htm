Upgrade license

 

Toolbar:   

 

Menu: CAD-Earth > License Management > Upgrade license

 

Command line: CE_UPGRADELICENSE

 

CAD-Earth version:  Basic, Plus, Premium.

 

Command description:

 

If you have the CAD-Earth Premium license, you already have access to all the CAD-Earth commands and you don't need to upgrade your license. If you have the Basic or Plus license, you can upgrade your license to Plus or Premium at any moment using this command.

 

 

 

After selecting this command, a dialog box will be displayed showing the current license type and the total number of licenses available. You must select from the list the license type you wish to upgrade to and then press the 'Continue' button.

 

 

If you have a CAD-Earth subscription, you must enter a six digit code sent to the registered email in your account.  If you don't receive this code after 2 or 3 minutes, please check the spam or junk mailbox. This code expires after 10 minutes, if you don't get the 6-digit code at this time interval, please contact us at support@cad-earth.com or submit a support ticket. If you have a permanent license, this step will be omitted.

 

 

A message will be displayed showing the current license type and the license type you selected to upgrade to. If you have a subscription, the upgrade price will be calculated taking into account the days left in your current payment cycle and the difference in price between the two license types. If you have a coupon, you can select the 'Have a discount coupon' link to enter the coupon code and apply the discount. After you press the 'I agree button', the upgrade amount will be charged to your account. If the payment doesn't succeed or if you don't have a subscription, you will be redirected to our web store where you can finish the payment process.

 

Tips:

 

•If the charge to your subscription account didn't succeed or if you don't have a subscription, you must apply the license again in each computer you have CAD-Earth installed to unlock the commands from the license type you upgraded to.

•You must have an Internet connection to upgrade the license.

•CAD-Earth demo licenses can't be upgraded.

•A license upgrades is not the same as a version update. A license upgrade is for changing from one license type to another to be able to access locked commands. Major and minor version updates are free for subscription users. If you have a permanent license, version updates are free for one year from the date of purchase.
