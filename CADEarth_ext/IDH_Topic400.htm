Create mesh from 3D faces

 

Toolbar:  

 

Menu: CAD-Earth > Mesh commands > Mesh from 3D Faces

 

Command line: CE_MESHFROM3DF

Prompts:

 

Select objects:

CAD-Earth version: Plus, Premium.

 

Command description:

 

This command can create a mesh by selecting existing 3D faces in the drawing. The 3D faces must be adjacent to another from one or more sides. The resulting mesh is 100% compatible with CAD-Earth commands.

 

Dialog box settings:

 

Dialog box to create a mesh from 3D faces

 

ØMesh properties.

 

•Name.  Enter text to identify the mesh. Must not contain the following characters: | * : ; > < ? , = ` \

•Description. Enter additional information about the mesh (optional).

                    Color. Select the color for the mesh lines and points.

•Layer. Select the layer where the mesh will be created.

•Visualization mode. The mesh can be displayed in any of the following visualization modes:

                    TIN: Mesh triangles with continuous lines.

                    Points: Mesh vertices will be shown as simple points with no size.

                    Boundary & Points: Triangle sides which are not adjoined to another triangle will be shown. Internal vertices will be displayed as simple points with no size.

                    Boundary Only: Only triangle sides which are not adjoined to another triangle will be shown, creating one or several outlines.

•Linear units. The distance unit selected will define the mesh scale factor. If the require unit is not included in the list, you can select 'Custom' at the end of the list to define a unit conversion factor.

•Linear unit to m factor.  The measure units used by CAD-Earth are meters, which are converted to the unit selected using this factor to display distance and volume calculations.

•Delete selected objects. Uncheck this box if you want to preserve the original 3D faces.

 

Tips:

 

•Use this command to convert a mesh created with previous CAD-Earth 6.0 versions to be compatible with the new format.

•If you open a drawing containing the mesh in another computer that doesn't have CAD-Earth installed, you must include the file CVLC_PointGroup.dbx (located in the CAD-Earth installation folder) in the same path as the drawing and load it with the APPLOAD command.
