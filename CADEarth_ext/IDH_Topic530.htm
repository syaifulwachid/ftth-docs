Mesh colors

 

Toolbar:   

 

Menu: CAD-Earth > Mesh commands > Mesh Viewer

 

Command line: CE_MESHVIEWER

Mesh Viewer toolbar:

CAD-Earth version: Premium.

 

Command description:

 

You can define colors for the mesh, background, lighting and wireframe lines, define the overall image intensity and contrast, and select to show the linked image and mesh wireframe.

 

 

 

Tips:

 

•If an image hasn't been linked with the mesh, the display linked image option will not be available.

•The surface color will only be applied in the linked image is not shown.

•To permanently save the mesh color settings, you must select save when closing the Mesh Viewer and save the drawing.
