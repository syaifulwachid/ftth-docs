Project vertices on plane

 

 

Toolbar:  

 

Menu: CAD-Earth > Mesh > Mesh Explorer.

Mesh Explorer node:

 

Context Menu: Vertices > Project vertices on plane

 

Command line: CE_MESHEXPLORER

 

CAD-Earth version: Premium.

 

Command description:

 

Mesh vertices inside an area or from the whole mesh will be projected onto a temporary plane to modify their elevation. The area can be selected specifying points on-screen or selecting an existing closed polyline.

 

When defining the temporary plane, a slope can be specified between the first point and the second and third point to define the slope of the plane in two directions.

 

Command line prompts:

 

Select: [Whole mesh/Area/Polyline]<W>:

Elevation offset<0.00>:

 

If the Area option is selected:

 

Select first point [or ENTER to exit]:

Select next point or [Undo]:

Select next point or [Undo]:

...

 

If the Polyline option is selected:

 

Select closed polyline:

 

To define the plane, the following prompts are displayed:

 

Specify first point:

Elevation<261.561>:

Specify second point:

Elevation or [Slope]<261.49>:

 

If the slope option is selected:

 

Slope from first point<0.00>:

 

Specify third point or ENTER:

Elevation or [Slope]<261.618>:

 

If the slope option is selected:

 

Slope from first point<0.00>: -2

 

Elevation<261.545>:

 

Tips:

 

•You can make a copy of the mesh and use this command to level a site inside an area, and then get the cut/fill volumes comparing with the original mesh using the volume grid method.
