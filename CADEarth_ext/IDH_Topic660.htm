Modify elevation

 

Toolbar:  

 

Menu: CAD-Earth > Mesh > Mesh Explorer.

Mesh Explorer node:

 

Context Menu: Vertices > Modify elevation

 

Command line: CE_MESHEXPLORER

 

CAD-Earth version: Premium.

 

Command description:

 

 

This command allows you to select a mesh vertex and change its elevation. The vertex elevation can be calculated by selecting a reference point to take its elevation, projecting the point on a temporary plane specifying three points, or specifying points to define a temporary mesh where the mesh vertices will be projected.

 An elevation offset can be specified, adding this value to the calculated elevation.

When defining the temporary plane, a slope can be specified between the first point and the second and third point to define the slope of the plane in two directions.

The current elevation mode (selecting a point on mesh or interpolating on a plane) and the current elevation offset are displayed before selecting an option.

 

You can define an area to project the vertices and modify their elevation. The elevation of the vertices inside the area will be calculated as follows:

 

•Fixed: Vertices will have a constant elevation.

•Select point: Vertices will take the elevation of the point selected.

•Interpolate: Vertices will be projected on a temporary plane defining three points.

•Project: Vertices will be projected on a temporary mesh created from the points selected, optionally specifying points inside this mesh to refine its configuration

Tips:

 

•You can select the area option selecting ground points around vegetation or buildings to remove them from the mesh.

•If you select the Project option, a mesh will be created, which you can use to calculate the mound, hole, or ditch volumes.
