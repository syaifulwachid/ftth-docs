Show contour lines

 

Toolbar:   

 

Menu: CAD-Earth > Mesh commands > Mesh Viewer

 

Command line: CE_MESHVIEWER

Mesh Viewer toolbar:

CAD-Earth version: Premium.

 

Command description:

 

The contour and index contour lines will be shown instantly using the specified gap, color and base elevation.

 

Contour lines dialog box.

 

Tips:

 

•You can move the cursor over a contour line to see its Z coordinate displayed in the lower left corner of the Mesh Viewer.

•The index contour gap must be a multiple of the contour gap.

•If you set the same gap for the index contour and contour lines, only the index contour lines will be shown.

•The base elevation will be the same as the bank level elevation used as a reference.
