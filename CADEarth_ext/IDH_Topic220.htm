Antivirus blocking CAD-Earth files

 

CAD-Earth EXE and DLL files are digitally signed and scanned to avoid being mistaken as threats by Antivirus Software.

Unfortunately, some Antivirus programs still detect some CAD-Earth files as containing virus, blocking access to some vital CAD-Earth functions.

The only solution to this problem is to exclude the CAD-Earth folder and files from the Antivirus scanning list and if possible report the CAD-Earth files as non-threatening and virus free.

 

The CAD-Earth files that may be blocked by an Antivirus Software are:

 

GEINTEROP.EXE

CADEARTH.EXE

CADEARTHX.EXE

CADEARTH.DLL

 

This files are located in the CAD-Earth installation folder.
