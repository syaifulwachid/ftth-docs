License manager

 

Toolbar:  

 

Menu: CAD-Earth > Help > License manager.

 

Command line: CE_LICMAN

 

CAD-Earth version: Basic, Plus, Premium.

 

Command description:

 

 

The License Manager is where the activation code is applied in order to authorize the use of CAD-Earth. You can also get a deactivation code so you can regenerate an activation code for a different computer.

 

To get a valid activation code you must go to the License Activation Center website and access your account. The access user name and password will be sent to your e-mail immediately after purchase confirmation to your email.

 

If you forget your password you can retrieve it in your registered email by giving your user name in the login page. If you have problems receiving or applying an activation code please contact technical support by selecting  'Contact technical support' in the CAD-Earth Help menu or by sending an email to support@cad-earth.com 

 

 

 

 

1.Site Code. This code generated automatically and is unique to each computer.

2.Get Activation code from the web. Pick this button to enter your username and password from your License Activation Center account. Then you can select the order from which the activation code will be automatically applied. After the activation code is applied, the number of licenses available will be decremented by one and the corresponding activation code will be added to the selected order in your License Activation Center account.

3.Copy Site Code. Press this button to copy the site code to the Windows clipboard. You can also select the site code, right click and select 'Copy' from the context menu.

4.Activation Code box. This is where you paste an activation code to authorize CAD-Earth.

5.Paste Activation Code box. Press this button to paste the activation code to the Windows clipboard. You can also right click inside the Activation Code box and select 'Paste' from the context menu.

6.Apply Activation Code. After applying the activation code, a message will be displayed with information about the status of the license.

7.Go to License Activation Center. Press this button to go to the License Activation Center website where you can manage your account information and activation codes. You will need your account user name and password.

8.Purchase license. Press this button to purchase CAD-Earth online. After purchase confirmation, you will immediately receive a user name and password to access your account in the License Activation Center website. Once there, you can generate a valid activation code.

9.Deactivation code box. A deactivation code will be displayed in this box after deactivating CAD-Earth.

10.Copy Deactivation code. Press this button to copy the deactivation code to the Windows clipboard. You can also select the deactivation code, right click and select 'Copy' from the context menu.

11.Get deactivation code. Pressing this button will deactivate CAD-Earth after confirmation. A deactivation code will be automatically generated, which you can use to generate an activation code for a different computer on the License Activation Center website.

12.Tooltip box. When hovering over a button or text box, the corresponding tooltip will be shown in this box.

13.Exit. Press this button to close the License Manager form.
