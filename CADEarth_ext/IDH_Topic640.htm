Delete

 

Toolbar:  

 

Menu: CAD-Earth > Mesh > Mesh Explorer.

Mesh Explorer node:

 

Context Menu: Vertices > Delete

 

Command line: CE_MESHEXPLORER

 

CAD-Earth version: Premium.

 

Command description:

 

Mesh vertices can be removed specifying a point, an area, or selecting an existing closed polyline. Vertices inside an area or closed polyline can be removed completely, specifying a minimum distance between points of zero. If this distance is set at a value different than zero, vertices will be removed until the distance between points inside the area is equal or less than the value specified.

 

Tips:

 

•You can remove points inside an area or closed polyline specifying a distance between points different than zero to reduce the number of vertices in areas where detailed information is not needed, and decrease the mesh size in the drawing to make it more manageable.
