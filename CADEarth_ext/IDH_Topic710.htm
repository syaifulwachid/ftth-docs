Project vertices on mesh

 

 

Toolbar:  

 

Menu: CAD-Earth > Mesh > Mesh Explorer.

Mesh Explorer node:

 

Context Menu: Vertices > Project vertices on mesh

 

Command line: CE_MESHEXPLORER

 

CAD-Earth version: Premium.

 

Command description:

 

Mesh vertices inside an area will be projected onto another reference mesh to modify their elevation. The area can be selected specifying points on-screen or selecting an existing closed polyline.

 

A message will be displayed when finishing, showing the total number of vertices whose elevation was modified, and the number of invalid points found.

 

The following dialog box will appear to select the reference mesh selecting a tree node or selecting the mesh in the drawing:

 

Dialog box to select a reference mesh

n vertices from original mesh projected on selected mesh.

(n) invalid points.

 

If the Polyline option is selected:

 

Select closed polyline:

n vertices from original mesh projected on reference mesh.

(n) invalid points.

 

Tips:

 

•You can insert vertices before using this command to increase the mesh density of the mesh if you need to capture a more detailed configuration from the reference mesh.
