License Activation Center

 

 

In the License Activation website you can manage your account information and activation codes.

After purchase confirmation, you will immediately receive a user name and password by email to access your account. You can select 'Go to License Activation Center...' in the CAD-Earth help menu or click the License Manager button to go to the login page.

 

Activation codes can be generated, removed or updated. To generate an activation code you must enter the site code from your computer. This site code can be copied from the License Manager site code box and then pasted in the License Activation Center site code box.

 

A deactivation code is needed to remove or update an activation code. To remove an activation code you must enter the deactivation code from the old computer. For each activation code removed successfully, you can generate a new activation code for another computer.

 

If you update an activation code, you must enter the deactivation code from the old computer and enter the site code from the new computer. The process of eliminating the activation code and generating a new one will be performed in one step.

 

Fig. 1: License Activation Center login web page.

 

1.User name and password boxes. After purchase confirmation, you will receive an email with a valid user name and password.

2.Remember me. If this box is checked, you can go directly to your account web page again in the same session without having to enter your user name and password.

3.Login button. Press this button to go to your account web page.

4.Forgot password?. By following this link you can enter your user name and receive the corresponding access password by email.

 

 

 

Fig. 2: License Activation Center order web page.

 

1.Order information. This row details information about the product purchased. Select 'licenses' to add, remove or update licenses and to display site and activation code for each license.

2.Update license icon. To update a license, you will need the site code from the new computer and the deactivation code from the old computer. After the update, the license information will be replaced with a new site and activation code for the new computer.

3.Remove license icon. To remove a license, you will need the deactivation code from the old computer. After license elimination, the license will be removed from the pool of activated licenses, and a new license can be generated.

4.Site code. This code is unique for each computer.

5.Activation code. You can copy the activation code from this box and paste it in the License Manager activation code box to authorize the program.

6.Add license icon. You must enter the site code from the computer to be authorized. The corresponding activation code will be generated automatically.

7.Send email icon. You can send information about the selected license to an email account. Order information such as order ID, number of licenses granted and activated, program name and version, site and activation code will be sent to your registered e-mail account (user name and password will not be included).
