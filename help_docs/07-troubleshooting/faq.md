# Pertanyaan yang Sering Diajukan (FAQ) 💬

Kumpulan pertanyaan umum dari komunitas drafter dan perencana jaringan FTTH.

---

### Q1: Apakah software ini bisa digunakan tanpa koneksi internet (offline)?
**Jawab**: **Bisa!** Seluruh fungsi inti desain (penomoran hompass, penempatan tiang, auto routing kabel Dijkstra, validasi, dan ekspor KMZ/BOM) dapat berjalan 100% offline. Koneksi internet hanya dibutuhkan saat mengunduh tile citra satelit baru dan verifikasi update versi berkala.

---

### Q2: Apakah lisensi bisa dipindahkan ke laptop lain jika komputer rusak?
**Jawab**: **Bisa.** Anda cukup menginformasikan ke Admin via WhatsApp dengan menyertakan bukti kepemilikan lisensi dan kode Machine ID laptop baru Anda. Kami akan membantu meriliskan kunci lisensi untuk laptop pengganti.

---

### Q3: Apakah bisa request format blok atau layer khusus sesuai SOP perusahaan/klien kami?
**Jawab**: **Bisa.** Template atribut dan layer tersimpan dalam file konfigurasi JSON transparan di folder `FTTH_Asset/`. Anda dapat menyesuaikan nama layer, warna, dan atribut blok sesuai standar template perusahaan Anda.

---

### Q4: Apakah hasil ekspor KMZ bisa langsung dibuka di aplikasi Google Earth HP Android / iOS?
**Jawab**: **Ya, 100% kompatibel!** File `.kmz` yang diekspor telah dioptimalkan agar ringan dibuka di aplikasi mobile Google Earth oleh tim survei maupun mandor konstruksi lapangan.

---
