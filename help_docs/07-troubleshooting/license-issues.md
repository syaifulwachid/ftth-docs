# Kendala Lisensi & Solusi Aktivasi 🔑

Halaman ini merangkum kendala paling umum terkait lisensi perangkat lunak dan cara mengatasinya dengan cepat.

---

## ❓ 1. Status Lisensi Berubah Menjadi "INVALID"
**Penyebab Umum**:
- Anda baru saja mengganti komponen perangkat keras utama komputer (misalnya motherboard, prosesor, atau kartu jaringan).
- Tanggal dan jam di sistem Windows komputer Anda tidak sinkron dengan waktu internet.

**Solusi**:
1. Periksa tanggal & jam Windows Anda: pastikan fitur *Set time automatically* aktif.
2. Jika Anda baru mengganti komponen PC / laptop baru, buka kembali jendela aktivasi, salin **Machine ID Baru**, dan kirimkan ke WhatsApp Admin [0822-3069-6953](https://wa.me/6282230696953) untuk migrasi lisensi.

---

## ❓ 2. File Lisensi `sysFTTH.cfg` Tidak Terbaca
**Solusi**:
1. Pastikan nama file tidak berubah (harus persis `sysFTTH.cfg`, bukan `sysFTTH(1).cfg` atau `sysFTTH.cfg.txt`).
2. Letakkan file tersebut di dalam direktori bundle plugin:
   ```text
   %APPDATA%\Autodesk\ApplicationPlugins\FTTHBasemap.bundle\Contents\
   ```
3. Restart aplikasi AutoCAD Anda.

---

## ❓ 3. Notifikasi Masa Aktif Telah Berakhir
**Solusi**:
- Lakukan pembayaran perpanjangan langganan bulanan via QRIS / Transfer Bank.
- Konfirmasi via WhatsApp dengan mengirimkan bukti transfer. Kunci perpanjangan akan dikirimkan dalam hitungan menit.
